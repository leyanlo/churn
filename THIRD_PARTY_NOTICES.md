# Third-party notices

Churn is an unofficial interface powered by third-party rendering software and preset data. Churn does not implement the MilkDrop renderer or port MilkDrop3's native implementation.

## Project lineage and artist credit

- [MilkDrop](https://www.geisswerks.com/milkdrop/) was created by Ryan Geiss.
- [Butterchurn](https://github.com/jberg/butterchurn), the WebGL 2 renderer used by Churn, was created by Jordan Berg and contributors.
- [Butterchurn Presets](https://github.com/jberg/butterchurn-presets) contains converted classic MilkDrop presets maintained by Jordan Berg and contributors. Individual preset names retain their original artist credits.
- [MilkDrop3](https://github.com/milkdrop2077/MilkDrop3), developed by milkdrop2077 and based on BeatDrop by Maxim Volskiy, inspired the original experiment. MilkDrop3 code and MilkDrop3-only presets are not included in Churn.
